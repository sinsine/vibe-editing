# 05 · 故事：把信息变成一次被引导的理解

> 输入是主题、文章或笔记；产物是 `STORYBOARD.md` 里的叙事。文件语法看 `storyboard-format.md`，
> 上游的接单与闸门看 `00-intake.md`，这一份只管故事本身：教什么、按什么顺序、每一帧为什么存在。

## 1. 唯一的硬规则

**文章是信息倾倒，视频是一次被引导的理解行为。**

不要跟着原文的段落顺序走。重排、合并、省略、压缩 —— 把原文当成**信息来源**，不是故事模板。
原地复述原文顺序是这类片子最常见的失败方式，也是唯一一种"每一步都没错、整体却没人看下去"的失败。

自检很简单：把你的帧序列和原文的小标题并排放。如果顺序一一对应、数量差不多，你就是在念稿。
原文里那些精彩的旁支、必要的限定条件、作者的自我更正，几乎都该被删掉或压成一句 —— 它们属于文章，不属于片子。

## 2. 先抽教学真相，再动笔写帧

写任何一帧之前，先把六件事写成六行。写不出来说明材料还没看懂，不要往下走。

| 项 | 标准 |
| --- | --- |
| Audience | 谁在看，以及他们**已经知道什么**（起点由后半句决定） |
| Gap / stakes | 那个让人不舒服的困惑或代价 —— "为什么我要关心"的答案 |
| Thesis | 一行，观众看完带走的那句话。它就是 `message` |
| Spine | 3–6 个推进到 thesis 的想法（机制、步骤、条目、情节） |
| Evidence | 具体的数字、例子、对照、算例 —— 不是形容词 |
| Landing | 落点：一句让他今天就能用的判断，或一个可执行的下一步 |

真实影片的六行：

- **受众**：高中生与大学生。他们知道"挑对象很难"，不知道这是一个有最优解的问题。
- **缺口**：一个躲不掉、又从来没人给方法的决定；大家只被告知"要勇敢"。
- **Thesis**：「你无法知道哪支麦穗最大，但你可以决定什么时候停下来」。
- **Spine**：恋爱问题 → 麦田寓言 → 反转：它是数学 → 37% 与 36.8% → 套到你的年龄 → 够好 vs 最好 → 升华。
- **Evidence**：37%（观察期）、36.8%（胜率）、63%（仍会错过）、21.7 岁、19.5 岁、+20%（求职对照）。
- **Landing**：21.7 岁之前建立标准，之后遇到达标的就下手；收尾问"你自己的标准，到了没有"。

围绕 thesis 写帧，不要围绕原文的小标题写帧。

## 3. 选一个结构

| 结构 | 适用 payload |
| --- | --- |
| `concept-explainer` | 一个受众半懂的概念：命名 → 逐层揭机制 → 落含义 |
| `how-to-process` | 有明确起止的流程或机制：3–6 步，同一舞台，一步一个动作 |
| `listicle` | 一组并列的条目（技巧、错误、理由）；三段式最稳 |
| `story-explainer` | 具体的叙事或案例：铺垫 → 张力 → 转折 → 收束 → 道理 |

复合结构要**显式命名**（`arc` 写 `<外层> with <内层>`），不要从两个结构里各剪一半拼起来。

真实影片用的是 **`story-explainer` 承载 `concept-explainer`**：

- 外层是故事 —— 麦田、第一支就很大、放下手、空手走出田埂、"这就是爱情"、砍树、"这就是婚姻"。
  它给出情绪与语境，让人愿意听完。
- 内层是概念 —— 把寓言写成题面（n 个选项、当场决定、不能回头）→ 37% → 36.8% → 63%。
  它给出可复核的答案。
- 为什么不反过来：受众是高中生和大学生。先给一个他们正在经历的处境，概念才有落点；
  先讲"最优停止问题"，钩子就变成一个术语，观众没有理由留下。

## 4. 前 3–5 秒的钩子

钩子只做一件事：让观众觉得"这是说给我听的"。可选策略（`story-design.md` 有完整目录）：
耸动统计、修辞提问、反直觉断言、痛点确认、感官化比喻、概念宣告、直接对话、想象场景、代价/风险。

规矩：

- 钩子说**观众的语言**，不是原文的小标题 —— "40% 更快"可以，"23 个文件变更"不行。
- **主张在第二个 beat 就落地**（`story-spine.md` §2 的反冰山）。之后的一切都是它的证据。
- 不要用定义开场，不要在钩子里塞术语。

真实影片用的是 **直接对话 + 修辞提问**：第 1 帧的 `display` 是「就是 ta 了？」四字从 0.42 s 起按拍落下，
两条 cue 分别是「有个问题，你迟早得回答。」（0.95–3.52 s）与「什么时候，才算"就是 ta 了"？」（3.6–6.61 s）。
第 2 帧立刻把处境具体化（标准每遇到更好的就抬高一格）—— 主张在第 2 帧就立住了。

body 通常不是一帧，而是 **3–6 帧跑在同一个舞台上**，每帧推进一个机制、一步、一个条目、一层。
孤立的一帧 body 什么也教不会。

## 5. 让抽象落到观众身上（最强的一招）

讲完规则就结束的片子，观众会说"有意思"，然后忘掉。真实影片在这里多做了一步：
**它把规则算到观众自己的年龄上。**

- 窗口取 18–28 岁 → `18 + (1/e) × 10 = 21.68` → **21.7 岁**，也就是大四。
- 换一个窗口，只看大学四年 → `18 + (1/e) × 4 = 19.47` → **19.5 岁**，大二上学期。

泛化规则：

1. 结尾把概念换成一个**属于观众的数字**，或一个**今天就做得成的决定**。
2. 在画面上写出**你假设的参数**（这里是 18、28、四年），观众才能改成自己的。
3. 给第二个算例。一个算例是结论，两个算例才是方法 —— 真实影片给了两个窗口，于是观众学会了"换窗口换答案"。

这是让一条教育片变得**可转述**的地方：能被记住、能被复述的从来不是公式，是"21.7 岁"。

## 6. 每个数字都必须算出来或引出来

规则：**算得出来的当场算，算不出来的标出处，两个都做不到就不要这个数字。**
一条教育片里错一个数字，比少一个数字严重得多 —— 前者毁掉的是整条片子的可信度。

真实影片的做法（可复制）：

- `data/optimal-stopping.json` —— 穷举精确最优 + 固定种子的 20 万次蒙特卡洛。n=100 时最优是先拒 37 个
  （r=38），P=0.371043；1/e=0.367879；`1 − 1/e = 0.6321205588`（即"仍有 63% 概率错过"）。
- `data/life-window.json` —— 1/e 换算：`18 + (1/e)×10 = 21.68`、`18 + (1/e)×4 = 19.47`。
- 每一帧用一行 `data:` 记录这个数字怎么来的，例如
  `data: data/optimal-stopping.json — n=100 精确最优 r=38（先拒 37），P=0.371043；1/e=0.367879；蒙特卡洛 20 万次，固定种子，与公式吻合`。
- 画面上唯一的**引用型**数字 `+20%` 带着出处一起出现：`Iyengar, Wells & Schwartz (2006)`，
  `Psychological Science 17(2):143–150`，第 30 帧的 `data:` 行照录。

同理，"够好 vs 最好"那组对照（目标"最好" 67% / "够好" 78%）是**本地模拟**（n=100，r=38 与 r=10，
固定种子），必须如实说成模拟，不能包装成定理。

**诚实案例**：文献里"最大化期望值"版本的最优策略至今没有定论，所以真实影片**不主张**它 ——
这条不写进片子，写进 `BRIEF.md` 的 `## Notes`。不主张一个文献本身没解决的问题，也是内容工作的一部分：
你不知道的地方，沉默比一句漂亮话更专业。

## 7. 静默是设计

不是每一秒都需要字幕，也不是每一格都需要大字。一个图自己在组装、一个数字自己落下来，
有时候不说话更有力。

- 静默有两种粒度：**帧级的"无大字"**（画面自己说话）和**拍级的空拍**（一帧的头半秒、尾半秒不放 cue）。
- 真实影片有 3 帧明确写了"无大字"：第 8 帧（手收回）、第 11 帧（手里是空的）、第 15 帧（拆掉"寓言=道理"的预期）。
  这三帧都是全片最响的地方 —— 删掉大字，动作才响。
- 允许完全静默的帧（`voiceover` 留空、不进 `SCRIPT.md`）。这时 `narrativeRole` 与 `persuasion` 必须自己扛下
  这一帧要说的全部信息，别让静默帧变成"过渡一下"。
  注：真实影片 33 帧每一帧都有一行字幕，一帧都没留空 —— 静默在这里表现为"不对每秒都说话"，不是"没有字幕"。

## 8. 字幕写成分段 cue，不要一口气

**每一条 cue 都是画面可以"揭示一次"的单位** —— 这就是反 PPT 机制。一句一口气的长句，会让这一格无事可做。

- 用「｜」把一帧的台词切成两条 cue。真实影片第 1 帧：
  `voiceover: 有个问题，你迟早得回答。 ｜ 什么时候，才算"就是 ta 了"？`
  → 两条 cue 分别落在 0.95–3.52 与 3.6–6.61，画面就按这两次揭示来排。
- **cue 的时间不要手写。** 帧只声明 `bars`（占几个小节），`scripts/sync-storyboard-timings.mjs` 按阅读负荷
  （CJK 1.0 / 拉丁字母数字 0.5 / 标点 0.3 / 空格 0.15）把每条 cue 拟合到拍线上。
  `start` / `end` / `duration` / `cues` 是**派生键**，每次全量重建，永不手改。
- `display`（中央大字）与 `voiceover`（字幕）必须**分工**：大字承担重音，字幕承担句子，两者不重复原文。
  真实影片第 22 帧：字幕是「这样做的胜率是 36.8%。」，大字是 `36.8%` 与倍率 `37×`。
  无旁白的片子更严：**字幕就是声音**，所以每行 ≤20 字、3–6 字/秒，重音交给大字。

## 9. 连续性：一个舞台 + 一种转场

框架是**一帧一个 worker**，没有"接着上一帧做"的机制。一段连续感只能靠两根杠杆，两根都是你的：

1. **一致的舞台** —— 相邻 body 帧共享同一个构图概念（同一条麦田带、同一条时间轴、同一张题面卡），
   并把它写进每一帧的 `scene`，让建帧的人不会各自发挥。
2. **一致的转场** —— 给一段序列固定一种缝（有序步骤用 `push-slide`，柔和的层次揭示用 `crossfade`），
   整段重复，于是它读起来像一条流，而不是一叠幻灯片。全片只挑 2–3 种；第 1 帧写 `cut`。

真正的**元素变形**要留在一帧之内（进场 → 变形 → 落定），不要劈到两帧的缝上。
例：第 27 帧把 `21.7` 翻牌成"大四"，整格只占一个小节（2.13 s）—— 变形和它的落点是同一个动作。

## 10. 两个闸门与提案里必须有什么

闸门的定义、人要判断什么、为什么脚本查不了美，见 `00-intake.md` §3。这里只说提案的内容：

- **一句复述**：「这条片子告诉 [受众]，[主张]。」
- **一张表**：`Frame | Beat | On screen | Why`，一行一帧。`Why` 是这一帧在故事里的职责，必须能一路追回主张；
  追不回的帧是要删的帧。
- **带依据的推荐**：结构选择（为什么是 story 承载 concept）、帧数、任何用户可能质疑的取舍，都要说出理由。
- **一句收尾**：可直接批准，也可只改一帧 —— 这一轮改一帧 30 秒，建完之后改一帧几分钟。

## 收尾自检

- [ ] 结构显式命名了；帧序列是叙事驱动的，不是原文段落顺序的映射。
- [ ] 钩子用了命名过的策略；主张在第 2 个 beat 就落地。
- [ ] 每帧只有一个职责；body 是一段（3–6 帧同舞台），不是孤立一帧。
- [ ] 六行教学真相写出来了，thesis 与 `message` 完全一致。
- [ ] 每个数字都能追到 `data:` 行或一条真实出处；模拟写成模拟；未定论的事不主张。
- [ ] 结尾把概念换成了观众自己的数字或决定，并写明了假设的参数。
- [ ] 每帧的 `voiceover` 是分段 cue，不是一口气；`display` 与字幕不重复。
- [ ] 静默是有意的（无大字或空拍），静默帧由 `narrativeRole` + `persuasion` 扛住。
- [ ] 连续段落共享一个舞台和一种转场；真正的变形留在一帧内。
- [ ] 转场只用注册名，全片 2–3 种，第 1 帧是 `cut`。
